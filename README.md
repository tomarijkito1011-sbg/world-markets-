# World Markets — 世界の株式市場ダッシュボード

世界40の国と地域の株価指数を、3D地球儀と平面地図で一目で見られるWebアプリです。

## 起動方法

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開きます（ポートは環境変数 `PORT` で変更できます）。

## 主な機能
- トップページ：3D地球儀と平面地図をボタンで切り替え。前日比で色分け（緑＝上昇、赤＝下落）。マウスを乗せると指数の詳細、クリックで国の詳細ページへ移動
- 詳細ページ：チャート（1日／1週間／1か月／1年／5年）、現在値・前日比・高値・安値、取引時間と開場状況（現地時刻・日本時間）、その国のほかの指数、同じ地域の市場
- 自動更新：開場中の市場は約15秒ごと

## ファイル構成
- `server.mjs` — 画面の配信と、Yahoo Financeからの株価の中継・キャッシュ
- `public/js/markets.js` — 市場の定義（指数、タイムゾーン、取引時間）。市場の追加はここに1行足すだけ
- `public/js/app.js` — トップページ（地球儀・平面地図・一覧）
- `public/js/country.js` — 詳細ページ

## 注意
株価データはYahoo Financeから非公式に取得しています。市場によっては数分〜20分程度遅れます。祝日の休場は株価の更新状況から推定しています。

## 指数の構成銘柄
- 銘柄リストは `public/data/constituents/` にあります（日経225、NYダウ、S&P500、FTSE100、DAX、CAC40、ハンセン、NIFTY50、SENSEX など17指数）
- 作り直すとき: JPXの「東証上場銘柄一覧」(data_j.xlsx) をダウンロードして
  `NODE_USE_ENV_PROXY=1 node scripts/fetch-constituents.mjs data_j.xlsx`
- 時価総額は「現在値 × 直近の決算で報告された発行済株式数」の概算です
